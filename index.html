How to Explain This Project in 30 Seconds

1. The Problem

Sequential Baseline (1 Worker)

Processes requests strictly one-by-one. When a request waits on I/O (e.g. 20ms database/network wait), the single thread blocks. 100 requests take ~2.05 seconds total.

2. The Solution

Bounded Thread Pool (8 Workers)

8 pre-allocated reusable workers consume tasks concurrently. While some threads wait on I/O, others process requests. 100 requests take only 0.27 seconds (7.6x speedup)!

3. The Safety Mechanism

Bounded Queue & Back-pressure

Unbounded queues cause memory exhaustion (OOM crashes). Our bounded FIFO queue enforces back-pressure: excess requests are rejected (REJECTED) immediately, protecting server stability.
